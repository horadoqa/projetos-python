Aprendendo Python
(Linha de Comando)

O parâmetro python3 -c permite executar um pequeno trecho de código Python diretamente pelo terminal, sem precisar criar um arquivo .py. É uma forma rápida e prática de testar comandos e experimentar a linguagem.

Somando valores

COMANDO 
$ python3 -c "print(sum([10,20,30,40]))"
SAÍDA 
100
